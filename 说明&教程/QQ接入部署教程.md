# AionsHome QQ 接入部署教程

把自己小家里的 AI 接到 QQ 群，与朋友一起聊天。AI 使用各自在小家聊天室配置的模型、人设、近期上下文和记忆，也可以把值得留下的经历带回自己的朋友记忆库。

本教程适用于 Windows 上已能正常运行的小家。支持先接入一位 AI，再添加另一位。凭据直接在小家页面填写，不需要准备配置文本、复制模板或运行导入脚本。

## 一 准备自己的小家

1. 更新包含 QQ 功能的 `aion-chat` 文件夹，保留自己原有的 `aion-chat/data`，不要用别人的数据覆盖。
2. 启动小家，确认自己的 AI 在小家聊天室里能正常回复，并为每位选择好模型。
3. 准备自己的 QQ 开放平台账号和一个目标 QQ 群。

本文中的「项目根目录」是包含 `aion-chat`、`.venv` 和 `一键启动.bat` 的文件夹。QQ 功能运行所需的代码、页面和重启工具都在 `aion-chat` 内，不依赖根目录的 `scripts` 文件夹；本功能不需要更新 Android 应用才能使用网页入口。

## 二 创建 QQ 机器人并加群

1. 登录 [QQ 开放平台](https://q.qq.com/)，按页面引导注册或完成认证，创建机器人，设置名称、头像等信息。
2. 进入该机器人的开发设置，取得 **AppID** 和 **AppSecret**。它们属于这个机器人，不是你的个人 QQ 号或 QQ 登录密码。
3. 按后台当前提示配置群聊能力、使用范围和测试人员。测试机器人若要求配置沙箱群，先把目标群加入允许范围；正式使用按后台要求完成审核、上线。
4. 使用有权限的 QQ 账号，在目标群的「群设置 → 群机器人」中添加机器人，或使用后台提供的机器人资料卡入口添加。
5. 如果要接两位 AI，分别创建两个机器人，保管好各自对应的凭据。

平台注册、凭据获取与添加机器人的入口可参考 [腾讯官方 QQ 接入说明的 QQ 渠道部分](https://cloud.tencent.com/document/product/1759/128832)。这里只使用其中的 QQ 平台步骤，不需要部署该文介绍的其他产品。

账号可用场景、沙箱限制和后台菜单可能不同，以自己的控制台为准。若后台启用了 IP 白名单，按要求填写运行小家的网络的公网出口 IP，不能填写 `127.0.0.1` 或局域网地址；更换网络后可能需要更新。[QQ 开放平台配置说明](https://github.com/tencent-connect/bot-docs/blob/main/docs/README.md)

## 三 在小家页面填写凭据

打开 **小家首页 → QQ 群聊 → 机器人接入**。首次未配置时，这一栏会自动展开，之后默认折叠。

1. 找到要接入的 AI。页面名称来自你自己的小家配置。
2. 在该角色下面填写对应机器人的 **AppID**、**AppSecret**。
3. 点击这一位的 **保存并连接**，等待凭据验证和连接结果。
4. 如需另一位，再填写另一组凭据并保存；两位不能使用同一个 AppID。

程序会自动把凭据保存到本机 `aion-chat/data/qq_social/credentials.json`，并生成内部管理密钥。**不需要你手动创建或编辑这些文件，也不需要上传它们。**

“已保存”表示本地配置已经落盘；角色卡片显示“在线”才表示 QQ 连接已建立。验证失败时原配置不变，可检查输入和网络后重试。

已保存的 AppSecret 不回显。以后 AppID 不变时，密钥框留空会保留原密钥；更换 AppID 或在 QQ 后台重置了 AppSecret，就填写对应的新密钥后重新保存。修改凭据会取消尚未完成的 QQ 回复，日常聊天不必反复保存。

## 四 打开开关并绑定目标群

1. 确认已配置的机器人显示在线。
2. 打开页面顶部的 **总开关**。首次配置默认不自动开启回复。
3. 打开对应角色卡片的 **参与群聊**，在回复设置中选中这位 AI，再选择 **仅 @ 回复**，在目标 QQ 群里 @ 它并发一句话。另一位可独立设置。
4. 回到小家 QQ 页面，确认「已连接的群」中出现对应群，并勾选 **参与**。

首次配对会允许每位机器人收到的第一个群；请先在你希望连接的群里测试。后续新增群默认关闭，需要在页面手动打开「参与」。两位机器人在同一个 QQ 群也会分别显示管理记录。

先确认 @ 能收到回复，再尝试普通聊天。不要把输入框里手打的普通昵称当作 @，应使用 QQ 的成员选择功能。

## 五 告诉 AI 哪个成员是你本人

用你的主 QQ 账号分别 @ 每位已接入的机器人说一句话，让它们各自收到你的消息。然后在小家页面依次打开：

**对应群的「聊天与记忆」→ 群成员 → 找到自己 → 备注 / 身份**

填写你希望使用的备注，在「这位是你本人（小家的用户）吗？」提示中选择 **确定**。其他群友选择 **取消**，保留为普通朋友。昵称不清楚时，可对照刚才发送的消息确认成员。

两位机器人需要分别设置；加入新群后也应检查身份绑定。绑定使用平台成员标识，同一账号在同一机器人和群作用域内改昵称，不会因此失去绑定。换 QQ 账号则需要重新设置。不要将其他朋友标成自己，否则 AI 会把身份理解错。

## 六 回复方式和记忆怎么设置

| 设置 | 作用 |
|---|---|
| 总开关 | 关闭后停止处理新聊天和回复，重新开启不补发旧消息 |
| 每位「参与群聊」 | 单独暂停这位的所有 QQ 回复、主动判断和后台记忆整理，不影响另一位或小家聊天 |
| 仅 @ 回复 | 被明确 @ 才回复，适合初次测试 |
| 主动接话 | 收到普通群消息后，按间隔和次数限制判断是否接话 |
| 每群「参与」 | 决定该机器人是否在这个群回复 |
| 每群「积累记忆」 | 是否整理这个群的交往记忆 |
| 外面的回忆 → 把 QQ 回忆带回小家 | 允许 AI 自己选择值得记住的经历，写入自己的朋友记忆 |

**主动接话还需要 QQ 平台允许机器人收到普通群消息。** 只在小家切换模式，不能补齐平台权限。群卡片显示「可见普通群消息」，表示程序已经实际收到过这类消息；「等待普通群消息」则还未观测到。

先在回复设置中选择 AI，再展开「聊天参数」，分别调整主动判断间隔、群上下文条数、图片等待时间和每小时回复上限。默认主动间隔为 120 秒、群上下文 35 条、每小时主动发言 6 次、全部回复 60 次；均按机器人和群分别计数。每位的模式和参数独立保存，切换角色不会覆盖另一位。旧版本升级时继承原有参数，不会自动关闭任何一位。

例如：模型费用较高的一位设为「仅 @ 回复」，另一位设为「主动接话」；暂时完全不用某位，就关闭它卡片上的「参与群聊」。仅 @ 模式仍可能整理群记忆，角色参与关闭才会同时暂停该角色的 QQ 后台记忆调用。总开关仍可一键暂停两位，重新打开保留各自开关。

主动接话由新消息触发，不会每隔固定秒数空跑模型，也不保证每句话都有回复。明确 @ 仍受总次数限制。想暂停聊天，关闭总开关即可，不用关电脑上的服务。

回复会尽量标明在接哪句话：被 @ 时自动引用点名消息；主动接话时，AI 在同一次调用里选择当前群上下文中近 5 分钟的一条消息，带引用回复。没有合适目标就安静；面向全群的发言可不引用。此功能无需额外开启，不增加一次模型调用，也不会自动 @ 打扰群友。引用能否显示需以 QQ 客户端实测为准。

带回的回忆在 **外面的回忆 → 管理朋友记忆** 中查看。它们进入各自的记忆库，也能被小家近期上下文参考；不会自动在小家聊天窗口发一条消息。没有新记忆不一定是故障，AI 不要求每次聊天都记。

**外面的回忆 → 小家同步近期互动** 是另一个独立开关，默认开启。AI 在 QQ 实际回复时，同一次模型调用顺便生成短摘要，发送成功后写入本地缓存；公开回复、长期记忆、近期摘要分开解析，格式错误时不发送模型原文。小家私聊和群聊会自动读取本人近期互动，不用再调用模型总结，也不会在聊天窗口插入消息。

每位、每个外部场景只保留一份摘要，内容限于两小时内的聊天；超过一小时没有新摘要，就不再加载。最多参考最近三个场景，较早的内容会缩短。已绑定的本人在群里出现和直接与该 AI 交谈分别记录，避免仅因小家没有新消息就误判很久没联系。

在 **外面的回忆 → 查看近期摘要** 中，可以分别查看每位 AI 当前有效的摘要、来源、更新时间和预计失效时间。入口和较长内容默认折叠，展开时随页面状态刷新；只读取本地缓存，不调用模型。暂无有效摘要时会显示空状态，过期内容不再列出。

觉得影响速度时可随时关闭「小家同步近期互动」：立即停止更新和加载，并清空短期缓存，不影响永久朋友记忆或 QQ 正常聊天。缓存位于被 Git 忽略的 `aion-chat/data/external_activity.db`；其他平台以后可以共用这一入口。本次升级后需重启一次小家与 QQ，之后切换开关不用重启。

## 七 图片和日常启动

发送图片后，同一个人补发文字，程序会合并图文并提前结束等待；不补文字默认最多等 60 秒，再按当前模式和限频判断。仅 @ 模式下仍需要 @ 机器人。图片识别要求配置的模型及调用线路支持图片；目前不读取语音、视频和其他文件。

日常启动小家仍可使用原来的 `一键启动.bat`，已配置的 QQ 服务会一起启动。**电脑或服务器要保持运行并联网**，关闭手机页面不会停止服务。

升级代码后需要重新加载两个服务时，在 `aion-chat` 文件夹内双击 **重启小家与QQ.bat**。它调用同文件夹的 `restart-home-qq.ps1`，后端在后台运行；无需等待群聊或回复停止，正在生成的回复可能中断。状态接口无响应也可以重启，服务已关闭时会直接启动。已加载新版后，页面修改凭据会自动重连 QQ，不需要每次重启小家。

## 八 常见问题

| 现象 | 先检查 |
|---|---|
| 首页没有 QQ 入口 | 更新 `aion-chat`，重启服务并刷新；也可在原小家网址后加 `/qq-social` 进入 |
| 接入设置提示暂不可用 | 若刚升级，先重启小家与 QQ，让新后端接口生效 |
| 凭据验证失败 | AppID 和 AppSecret 是否属于同一个机器人，密钥是否已重置，网络能否访问 QQ 接口 |
| 已保存但没在线 | 看角色卡片的错误信息；检查平台权限、IP 白名单及网络；稍后点保存并连接重试 |
| 在线但 @ 不回复 | 总开关、该角色的参与群聊开关、该群的参与开关、机器人是否真正收到 @，以及小家聊天室的模型配置；在线只表示连接正常 |
| @ 能回复，普通消息不回复 | QQ 是否开放普通群消息接收、是否选择主动接话、是否仍在冷却或达到上限 |
| 成员列表找不到自己 | 总开关和群参与打开后，再用自己的账号 @ 对应机器人发一句话 |
| 朋友记忆没有内容 | 检查带回开关；AI 只保存它认为值得留下的回忆 |

需要协助时可提供页面报错和经过检查的日志片段。QQ 日志位于 `aion-chat/data/qq_social/worker.stderr.log`；不要直接发送整个 `data` 文件夹或包含 AppSecret 的截图。

## 九 更新代码与私人数据

日常更新 **`aion-chat` 中的程序文件即可，保留本机 `data`**。不要复制别人的 `data`，也不要在发布源码时包含自己的 `data`。QQ 页面、连接程序和重启工具均随 `aion-chat` 一起分发；无需另找导入脚本或凭据模板。

QQ 配置、群消息、身份绑定和群交往记忆保存在 `aion-chat/data/qq_social/`；带回的朋友记忆保存在 `aion-chat/data/chat.db` 中，按角色分开。现有 Git 忽略规则保护这些文件，备份时请另行备份自己的数据。

群里的 AI 会参考自己的小家记忆来回复，因此应选择你愿意让它参与的群。每个人部署自己的小家、填写自己的机器人凭据，彼此的记忆库不会因为进入同一个群就自动合并。
